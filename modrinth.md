Тонкие палочки и стебли бамбука, которые ставятся в пустую клетку. Minecraft 1.21.1. Ставится один загрузчик, не оба сразу.

## NeoForge

Обязательно: `placedsticks-neoforge-1.21.1-1.0.0.jar` и Kotlin for Forge 5.8.0.

## Fabric

Обязательно: `placedsticks-fabric-1.21.1-1.0.0.jar`, Fabric API `0.116.17+1.21.1` и Fabric Language Kotlin `1.13.2+kotlin.2.1.20`. Строка «нужен fabric 0.100.3» означает jar Fabric API, не Fabric Loader.

Place sticks and bamboo stalks as thin rods. Minecraft 1.21.1. Install one loader, not both.

## NeoForge

Required: `placedsticks-neoforge-1.21.1-1.0.0.jar` and Kotlin for Forge 5.8.0.

## Fabric

Required: `placedsticks-fabric-1.21.1-1.0.0.jar`, Fabric API `0.116.17+1.21.1`, and Fabric Language Kotlin `1.13.2+kotlin.2.1.20`. A line that says "requires fabric 0.100.3" means the Fabric API jar, not Fabric Loader.
